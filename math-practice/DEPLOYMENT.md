# Deployment

## Public application
https://spcolello.github.io/math-practice/

## Hosting
The application is deployed through the public GitHub Pages repository:

https://github.com/spcolello/SeanColello.github.io/tree/main/math-practice

Because this is a static HTML/CSS/JavaScript application, no build step or backend server is required. The files in the `math-practice/` folder are served directly by GitHub Pages.

## Final verification
Before submission:
- Open the public URL in a private/incognito window.
- Start a session and answer several questions.
- Confirm mistakes appear in Mistake Review.
- Confirm statistics update.
- Refresh the page and confirm data persists.
- Confirm the site works on a narrow/mobile-size browser window.
