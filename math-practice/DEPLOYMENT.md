# Deployment and Release Verification

## Public URL
https://spcolello.github.io/SeanColello.github.io/math-practice/

## Release checks
- Run `npm run verify`.
- Verify Practice, Mistakes, Statistics, and Settings.
- Complete fixed and continuous sessions.
- Refresh during an active session and confirm recovery.
- Attempt navigation during an active session and confirm a warning.
- Create a mistake, practice similar questions, and verify mastery progress.
- Refresh and confirm statistics/settings/mistakes persist.
- Test Chrome, Edge, Firefox, and Safari when available.
- Test mobile/tablet widths, 200% zoom, and reduced motion.
- Confirm no development console errors.
